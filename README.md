# Amazon Clone in Vue.js

This is the same project as the Amazon clone in main branch, but now migrated to using Vue and no longer pure HTML/CSS/JavaScript.
Benefits of migrating to Vue allows for clearer separation of components and allows for smaller codebases to easily debug issues.

This Vue specific project will have an Orders and Tracking page, which the regular JavaScript version of this project does not have, so essentially, all parts of this project are fully functional, aside from the "Buy it again" button, which is not planned to be implemented.
